Connect Claude Desktop or Claude Code (MCP)

Paste the JSON below into Claude Desktop's config file:

{
  "mcpServers": {
    "yt-summary": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "{{ base_url }}/mcp/sse",
        "--header", "Authorization:Bearer {{ plaintext }}"{% if not is_https %},
        "--allow-http"{% endif %}
      ]
    }
  }
}

Config file location:
macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json
Linux: ~/.config/Claude/claude_desktop_config.json

For Claude Code, run this one-liner — it writes the right config for you:

claude mcp add yt-summary -- npx -y mcp-remote \
  {{ base_url }}/mcp/sse \
  --header "Authorization:Bearer {{ plaintext }}"{% if not is_https %} \
  --allow-http{% endif %}
